ADLS Gen2	Training storage for raw, curated and governed data
Lakeflow	Required capabilities enabled for ingestion, transformation and pipeline exercises
Azure Data Factory	Training instance with representative/sanitized pipelines
Azure Synapse	Reference environment or representative pipeline definitions for migration POCs
Genie / AI-BI	Feature availability and permissions for agreed hands-on exercises
Repository	Approved Git, Azure DevOps or GitHub repository
Datasets	Sanitized customer-like datasets, including historical and lookup data
Participant devices	Corporate laptops, current browser, reliable Internet/VPN and approved client tools
